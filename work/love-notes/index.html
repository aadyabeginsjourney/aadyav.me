Love Notes: Valentine Notebook Prints

A Valentine’s print collection for notebook covers: ten repeat prints built from cherries, swans, strawberries, flowers and winged hearts.

Collection
Ten repeat prints, each built from a single tile.
Motifs
Cherry, swan, strawberry, daisy and bouquet; lavender, leaves, winged hearts and a trellis.
Application
Notebook covers.

Mood board

The collection began with love in its softest form: garden blooms, swans in pairs, cherries and blush pinks.

Colour board

Ten prints

Every print pairs one primary motif with a secondary one, on a ground from the colour board.

Ten prints, ten notebooks: each cover can stand alone or sit in a stack.

From tile to repeat

Each print started as one square tile, set up to repeat edge to edge across the cover.

On the desk

Mockups: the magenta bouquet, strawberry butter and swan pair prints as finished notebooks.
